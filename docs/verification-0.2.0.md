# 0.2.0 归并验证

2026-10-11，在 Minecraft 26.1.2 / NeoForge 26.1.2.114 的目标实例完成构建、测试与受控安装。正式产物为 `SISE-Compat-0.2.0+26.1.2.jar`，配套 `SISE-Ores-0.3.1+26.1.2.jar`。

## 归并结果

- 注册表并发与 EnderIO 化学导管的独立模组入口退役，全部源码、资源和后续维护放在 SISE Compat。
- Artifacts、AAA Particles、EnderIO Evolution、Titanium、AE2 Screenshot 恢复对应上游原版 JAR，兼容修复由 Compat 的 Mixin、事件与资源提供。
- Ores 的 15 条矿物格式修复、12 条材料冲突处理、手动转换保护与 RarityCore 同步快照迁入 Compat；Ores 保留材料注册、统一与世界生成。
- 旧独立工程和截图补丁源码移入本地历史证据目录，不再作为独立交付入口。
- 窗口原生保护按用户要求保持原工程与原 JAR。安装前后校验 208 个其他 JAR 和 118 个游戏核心、库及原生文件，哈希均保持一致。

## 验证边界

当前包有 3 对原有工作台同输入候选：CakeStickLib / Industrial Foregoing 的金齿轮与铁齿轮，以及 Extended Crafting 红石锭 / ProjectE 中等共价粉。原配方在本次补丁应用前即可满足同一输入，本次归并没有引入这些冲突。相较更早的 0.1.x 冻结基线新增的模组会产生这 3 对差异，不能将历史基线差异计为本次迁移新增。

原 43 对合成冲突回归均不再复现，21 条失效配方继续恢复。仍保留 73 对原有自动机器候选；没有逐台运行所有机器、穷举随机副产物或跨机器循环。缺少实际注册物品的 `avaritia:eio_creative_power` 继续按条件禁用。

专用服务端在 Modern Industrialization `2.5.0-viking602.3` 构造阶段因引用仅客户端存在的 `net.minecraft.client.renderer.block.BlockAndTintGetter` 而退出，尚未进入本次服务端探针；专服结果不计为通过。客户端及集成服务端的完整测试已通过。Ores 世界生成算法、材料清单和资源未改，既有普通地形世界生成验证见 [0.3.0 记录](https://github.com/SISE-Team/SISE-Ores/blob/26.1.2/docs/verification-0.3.0.md)；本次包含矿石掉落与结构过滤回归，没有重新宣称完成普通地形全量生成测试。

本地完整证据在 `verification/consolidation-0.2.0/`，包括测试模组集合、候选 SHA-256、运行补丁报告、客户端／导管／截图结果、专服日志与安装证明。旧 JAR 和退役源码在实例 `.work/outputs/compat-consolidation-20261011/`。源码仓库只保留摘要，维护规则见 [COMPAT_POLICY.md](COMPAT_POLICY.md)。
