# Compat 维护约定

用户要求：我们自己的 Compat 修复全部放在 SISE-Compat，不再独立拆出。用户随后明确排除窗口原生保护。

1. 所有整合包兼容补丁的源码、资源和构建入口在本工程；正式入口是 `sise_compat`，产物为一个 `SISE-Compat-<版本>.jar`。
2. 不新建独立 Compat 模组，不将兼容类或配方修改打进上游发行 JAR。优先使用运行时 Mixin、事件或资源覆盖，并标明审核版本及来源。
3. SISE Core 的基础功能、SISE Ores 的材料与世界生成、原模组的正式版本移植留在各自工程；独立的上游故障修复统一由 Compat 提供。
4. 窗口原生保护保持现有实现，不属于本次归并范围。
5. 迁入后取消旧的正式模组入口和安装产物，原注册 ID、协议、配方数量与玩家数据语义保持。旧源码、构建产物和日志可在历史证据目录保留。
6. 测试探针可使用独立测试入口，但只进入 `.work/test-*`，不得打包或安装到正式实例。
7. 更新前核对上游版本，运行与变更相关的回归；安装必须使用实测的同一 JAR，并保存备份与游戏文件哈希。
