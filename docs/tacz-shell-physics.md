# TaCZ 弹壳落地修复

审核版本为 TaCZ Renovated `1.1.8+neoforge.26.1.2.R3-hotfix2`，修复由 SISE Compat `0.2.2+26.1.2` 的客户端 Mixin 提供。

## 原因

检查安装 JAR 的 `com.tacz.guns.client.model.functional.ShellRender` 后确认，原实现缓存抛壳节点的矩阵，按墙钟时间计算匀加速位移和持续旋转；没有查询方块碰撞，也没有落地状态。`extract` 在第一人称使用 `RenderTypes.itemCutout`，弹壳与手持物品进入同一渲染阶段。Minecraft 26.1.2 在渲染手持物品之前清除世界深度，所以弹壳不能按世界地面的深度正常遮挡。缓存相对相机的矩阵还会让弹壳在玩家移动后缺乏稳定的世界位置。

原始 TACZ 的 [ShellRender 源码](https://github.com/MCModderAnchor/TACZ/blob/1.20.1/src/main/java/com/tacz/guns/client/model/functional/ShellRender.java) 同样只有按时间播放的位移；当前移植版另外采用了新的渲染状态提取接口。本次以实际安装版本的字节码和本机 NeoForge 26.1.2.114 API 为依据。

`0.2.1` 仍有两个问题。TaCZ 的 `BedrockCubePerFace` 为未指定 UV 的面生成四个重合在原点的占位顶点；这些零面积面不会绘制，但旧碰撞测量把它们变换到骨骼枢轴后也计入边界。`.308` 弹壳的半高因而从实际的 `0.0172` 格被撑大到 `0.2053` 格，可见弹壳离地。旧验证只检查碰撞盒底面，没有测量可见模型。新增的可见面验证对原 `0.2.1` 产物确实失败：`tacz:792x57` 在草地上的模型底面离地约 `0.3763` 格。对应失败记录保留在 `verification/tacz-shell/previous-result-*.json`。

机枪 `tacz:minigun` 使用 `.308` 弹壳，枪包水平抛壳参数为初始 9、随机追加 0～2。把短时手持动画的参数直接用于持续世界运动，飞行距离过大。新版缩小初速度并限制世界速度；重力也不再受手持模型缩放影响。

## 实现

- `TaczShellRenderMixin` 取出原抛壳队列，每枚弹壳只生成一次客户端模拟对象。仍使用枪包的抛壳节点、方向、随机变化、角速度、弹壳模型与材质。
- `TaczWorldShells` 在生成时将节点坐标转成世界位置。Vanilla 26.1 手持矩阵已包含相机旋转；Iris 手持渲染另作一次明确的相机坐标转换。重力固定朝世界下方，不随枪口俯仰倾斜。
- `ShellShape` 按四个顶点一组测量真正有面积的面，排除未绘制面的占位顶点；其中心和边界包含骨骼位移与旋转方块，选择最薄的尺寸为落地时的竖直方向。
- 初速度及随机速度变换到世界后乘以 `0.25`，水平速度上限 `2` 格/秒，竖直初速度限制在 `±1.5` 格/秒。恒定世界重力为 `9.81` 格/秒²，不再使用动画的持续横向加速度。该速度限制是视觉调校，保留枪械抛壳方向，使常规持枪高度下的弹壳在枪旁落地。
- `ShellBody` 每游戏刻进行四次子步模拟，通过原版 `Entity.collideBoundingBox` 查询真实方块碰撞形状，处理地面、上下半砖、楼梯和墙体。弹跳逐次衰减，之后滑动停止并停止旋转；支撑方块消失后重新下落。
- `ExtractLevelRenderStateEvent` 冻结弹壳顶点、法线和世界光照；`SubmitCustomGeometryEvent` 以 `entityCutout` 提交到世界不透明阶段，使用世界深度。提交阶段不读取实时世界或可变模型。
- 默认至少显示 8 秒，枪包更长的生存时间保留但限制为 30 秒；全局最多 256 枚，64 格以外不绘制。暂停时不推进模拟，切换世界和资源重载时清理。

仅对本地玩家启用，沿用 TACZ 原来的视角与 `isSelf` 限制。弹壳是客户端视觉对象，不产生可拾取物品、服务器实体或存档数据。未审核的新 TACZ 版本不会应用此 Mixin。

## 验证

测试源码在 `src/taczprobe`，本地脚本为 `tool/tacz_shell_verify.py`，使用 `.work/test-tacz-shell-20261011` 的离线身份和全新平坦世界。专项覆盖枪包各口径的模型边界、草方块、上下半砖、楼梯两级、高速撞墙、支撑方块移除、原生抛壳提取钩子、禁止手持阶段重复提交、数量上限、切换武器和转动视角后的世界绘制。落地检查另外从提交的模型面重新测量可见底面，不能仅凭碰撞盒判断成功。所有带弹壳的枪械还在枪口俯仰 `-80°/0°/80°`、随机速度最小/最大两端下验证飞行高度、距离和可见模型落地；原生机枪渲染的弹壳另有真实运动距离及可见贴地检查。保存站立视角和距地面约 `0.16` 格的低视角 GPU 截图。

本地完整证据位于 `verification/tacz-shell/`。安装使用通过专项的同一候选 JAR，并检查原 Minecraft 文件、TACZ 发行 JAR 及其他模组哈希；旧 Compat 产物另行备份。

2026-10-11 的完整客户端专项已通过：23 个带弹壳的弹药条目（含共享模型）、115 组表面碰撞、270 组枪械轨迹、73,503 项断言。在测试的生成高度下，全部枪械最远水平移动 `1.5913` 格；正常机枪渲染产生的 9 枚弹壳最远水平移动 `0.8260` 格，全部可见底面贴地。切换为纸张并转动视角后，原弹壳的世界位置和落地状态保持不变，世界提交阶段实际运行 122 帧。低视角相机距地面 `0.1600` 格，确认弹壳位于画面内，并人工检查 GPU 截图中的底面接触。另通过 262 项配方保护断言和 49 项材料冲突断言。碰撞检查允许原版浮点接触误差 `1e-6` 格，碰撞盒和可见底面的落地高度误差均要求小于 `0.002` 格。

正式安装文件为 `mods/SISE-Compat-0.2.2+26.1.2.jar`，SHA-256：`c135715ce70a91f5a9560a18af2a8a8193c4a833a520466d66fc20a6606ec9d9`。已核对 14 个受保护的游戏文件与全部其他模组哈希不变；TACZ 使用原发行 JAR，87 条现有配方规则保持。旧 `0.2.1` Compat 已备份到本机 `.work/outputs/tacz-shell-fix-20261011/SISE-Compat-0.2.1+26.1.2-before-9e9ab4a27518.jar`。本次只对独立测试世界运行探针，未打开玩家存档。GPU 检查使用本实例当前未选光影包的设置；Iris 启用具体光影包的分支依据移植版源码实现，未做对应光影包的实机验证。

本地重复专项使用以下工具；安装器要求最新测试完成、候选与测试实例 JAR 哈希一致、正式模组集合与准备时一致：

```powershell
python tool/tacz_shell_verify.py prepare
python tool/tacz_shell_verify.py launch
python tool/tacz_shell_install.py
```
