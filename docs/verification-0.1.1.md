# SISE Compat 0.1.1 验证摘要

本记录整理自 2026-10-11 已完成的 project02 完整客户端与实机验证。验证组合为 SISE Compat `0.1.1+26.1.2`、SISE Ores `0.2.0`、NeoForge `26.1.2.114`，包含全部 208 个正式模组；测试探针仅存在于独立测试目录。

这份记录是已有测试的结果摘要。上传源码不会重新运行游戏，也不会把静态构建检查计为新的游戏实测。

真实容器操作包含 69 条工作台、5 条四阶终焉工作台、192 条切石机配方。通过客户端容器点击包取出成品，由服务端真实扣料；检查成品及组件、原料消耗和结果槽。机器放置在世界中，投料供能后等待正常 tick 加工，检查原料、产物和实际能耗。

实机发现 MI 原有的 8 条正反变压器配方可以绕过新增转换的组件保护，0.1.1 为这些入口补上同一 pristine 原料限制。12 条命名变压器反例均拒绝产出。

MI 原材料制作升压变压器时，输入还满足原有能源仓配方，需要使用机器自身的配方或输出锁定。锁定后实际加工通过；四档升压转降压均正常运行。73 对原有机器候选未宣称全部消除，也未穷举所有流体链、随机副产物、任意组件或跨机器循环。

缺少 `enderio:creative_power` 与 `enderio:vibrant_capacitor_bank` 的配方按条件禁用，不计为恢复可合成。
