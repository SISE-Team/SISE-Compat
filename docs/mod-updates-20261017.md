# 0.4.1 模组更新适配

- KubeJS 26.1.2-8.0.7 的世界加载 Mixin 已由上游修复，恢复使用未修改的官方发行 JAR。其 `kubejs.plugins.txt` 仍声明包内不存在的 ArchitecturyIntegration 类，`KubeJSPluginsMixin` 在插件枚举入口仅过滤该准确声明，且仅对审核版本启用。其余插件继续正常加载并报告自身错误。
- Titanium 4.0.12 的 PlayerInventoryFinder MAIN 仍将库存索引传给 Player.getSlot，保留原先的库存寻址修复，并将版本条件扩展到已检查的 4.0.12。验证覆盖所有槽位、越界索引、普通拾取和四种背包位置的数量守恒。
- EnderIO Evolution 可选依赖范围接受已审核的 4.0.2；现有两条化学导管数据定义继续保留 Mekanism 加载条件和传输参数。
- 冰火传说 2.2-beta.4 已删除旧铜工具与铜甲的九条配方，退役这些配方专属规则。其余配方仍由完整 JSON 来源校验保护。
- SISE Ores 0.7.1 在自身世界生成资源中跟随 Oritech exp11 的加权矿脉格式；不修改上游 JAR。
- 修复两项既有暮色 JEI 显示故障：权杖修复支持 NeoForge 自定义原料；无模板锻造配方使用暮色公开的原料接口。只对暮色 4.8.4208 与 JEI 29.47.0.111 的审核组合启用。
- 冰火传说 2.2-beta.4 的默认 ProjectE 转换文件重复声明狮鹫爪 4096／128，导致 ProjectE 拒绝整份文件。仅在完整来源 JSON 匹配时移除后续重复项，遵循 ProjectE 原有首项优先规则保留 4096 及其余新声明。用户改动的文件不覆盖；原版发行 JAR 不变。

本轮独立测试入口位于 `src/updateprobe`；仅打包到 `.work/test-*`，不进入正式 JAR。复用现有生产比例、事务扣料、库存拾取、结构并发和配方执行检查，同时运行厨房／酒馆的完整验证。实际运行结果、安装清单和备份位于实例 `.work/mod-updates-20261017/`。
